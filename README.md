# Econometric Analysis of Price Factors

## Описание
Проект посвящен эконометрическому исследованию влияния факторов на ценообразование стоимости елочной игрушки

## Данные
Данные были спаршены с сайта елочных игрушек и загружены в базу данных, потом были обработаны и отобраны основные регрессоры.

## Подход
- Предобработка данных
- Анализ признаков
- Составление регрессионной модели
- Итерпретация результатов модели, анализ значимости коэффициентов
